# Students Marks Performance

A machine learning web application that predicts whether a student will pass or fail based on attendance, homework, midterm score, and study hours.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Logistic Regression
- Streamlit

## Features

- Student performance prediction
- Pass/Fail classification
- User-friendly Streamlit interface
- Prediction based on academic performance data
